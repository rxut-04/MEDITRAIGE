# Abhyas AI — Phase 1

## Monorepo Structure
- `frontend/`: React + Vite + Tailwind + GSAP
- `backend/`: FastAPI Skeleton (Node.js/Express implementation for Cloud Run)

## Setup
1. `npm install`
2. `npm run dev`

## Features
- Smooth Scroll (Lenis)
- GSAP ScrollTrigger Animations
- Custom Cursor
- Responsive Landing Page
